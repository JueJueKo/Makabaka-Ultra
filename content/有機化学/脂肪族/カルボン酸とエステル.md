# 1. カルボン酸

## 1.1 カルボン酸とその性質

1. カルボン酸の分類
    - 分子中にカルボキシ基 $-COOH$ をもつ化合物を総称してカルボン酸という
    - 一価カルボン酸（モノカルボン酸）、二価カルボン酸（ジカルボン酸）などに分類
    - 飽和・不飽和、脂肪族・芳香族 などの区分
2. 一価カルボン酸の例
    - ギ酸 ($HCOOH$)、酢酸 ($CH_3COOH$)、プロピオン酸 ($C_2H_5COOH$)、酪酸 ($C_3H_7COOH$) など
    - 芳香族カルボン酸として安息香酸 ($C_6H_5COOH$) などがある
3. 脂肪酸
    - 鎖式一価カルボン酸の総称を特に脂肪酸ともいう（例：パルミチン酸、ステアリン酸など）

## 1.2 カルボン酸の一般的性質

1. 酸としての性質（弱酸性）
    - 水溶液中でわずかに電離し、  $R-COOH \leftrightarrow R-COO^- + H^+$
    - 塩酸や硫酸などの強酸よりは弱い酸性
2. 塩との中和反応
    - $$R-COOH + NaOH \rightarrow R-COONa + H_2O$$
3. 炭酸やフェノールよりも強い酸性
    - $$R-COOH + NaHCO_3 \rightarrow R-COONa + H_2O + CO_2$$
4. アルコールと反応してエステルを生成（エステル化）
    - $$R-COOH + R'OH \leftrightarrow R-COOR' + H_2O$$
5. 第一級アルコール → アルデヒド → カルボン酸
    - 一次アルコールが段階的に酸化されると最終的にカルボン酸となる

- (参考) [アミノ酸](タンパク質とアミノ酸)
    - 分子内に $-COOH$ と $-NH_2$ をもつ化合物
    - 味の要因など多彩な生理活性を持ち、塩基性・酸性両方の性質をもつ両性イオンとなりやすい

## 1.3 ギ酸 ($H-COOH$)

1. 製法
    - メタノールやホルムアルデヒドの酸化によって生成
2. 性質
    - 分子中にアルデヒド基 $-CHO$ があるため、還元性を示す（銀鏡反応など）
    - 沸点約101℃、無色で刺激臭のある液体
    - 強酸性で腐食性がある

## 1.4 酢酸 ($CH_3-COOH$)

1. 製法
    - エタノールやアセトアルデヒドを酸化 CH3CH2OH→酸化CH3CHO→さらに酸化$$CH_3CH_2OH \xrightarrow{\text{酸化}} CH_3CHO \xrightarrow{\text{さらに酸化}} CH_3COOH$$
2. 性質
    - 沸点118℃の無色刺激臭をもつ液体
    - 水溶液中で4～5%ほどの濃度のものは酢酸（食酢）として利用
3. 無水酢酸 ($CH_3-CO-O-CO-CH_3$)
    - 酢酸蒸気を加熱し、強力な脱水剤を加えると生成
    - エステル化やアセチル化に用いられる

## 1.5 ジカルボン酸（二価カルボン酸）

1. シュウ酸 $(\mathrm{(COOH)_2})$
    - 最も簡単なジカルボン酸で $H_2C_2O_4$ と表される
    - 無色結晶で強い酸性、加熱すると $CO$ と $CO_2$ に分解
    - アルカリ土類金属イオンと白色沈殿をつくる（Ca$^{2+}$ との沈殿など）
2. アジピン酸 ($\mathrm{HOOC-(CH_2)_4-COOH}$)
    - [ナイロン66](熱可塑性樹脂)の原料として重要
    - 縮合重合によりヘキサメチレンジアミンとの反応でナイロン66を生成 $$\text{n}NH_2-(CH_2)_6-NH_2 + \text{n}HOOC-(CH_2)_4-COOH  \rightarrow \text{ナイロン66} + \text{n}H_2O$$
## 1.6 マレイン酸とフマル酸

1. マレイン酸 (cis-体)、フマル酸 (trans-体)
    - 最も簡単な不飽和ジカルボン酸 $,HOOC-CH=CH-COOH,$
    - cis-形がマレイン酸、trans-形がフマル酸
2. 加熱による脱水
    - マレイン酸は約160℃で脱水して無水マレイン酸になる
    - フマル酸は同条件で変化しにくい

# 2. ヒドロキシ酸

## 2.1 ヒドロキシ酸の概要

1. 分子中にヒドロキシ基 $-OH$ とカルボキシ基 $-COOH$ の両方をもつ化合物
2. 代表例
    - 乳酸 ($CH_3-CH(OH)-COOH$)
    - リンゴ酸 ($\mathrm{HO-CH_2-CH(OH)-COOH}$)
    - 酒石酸 ($\mathrm{HO-CH-COOH}$ の二価構造)
    - クエン酸 (レモン、ミカンなどの柑橘類に多く含まれる)
